# Curated always-on skills for the deepseek profile.
#
# Only the skills listed below are registered with opencode (via
#   ~/.config/opencode/skills-deepseek-curated, a folder of symlinks).
# Everything else stays untouched in the full pack
#   ~/.config/opencode/skills-deepseek/<name>/SKILL.md
# (not scanned, so its description costs no context) and can still be read
# directly on demand when a task needs it.
#
# Edit this list, then:
#   bun ~/.config/opencode/tools/curate-skills.mjs --fix     # apply
#   bun ~/.config/opencode/tools/curate-skills.mjs --check   # verify (exit 1 on drift)
# and restart opencode (config is not hot-reloaded).
#
